# Site chat assistant

The "Ask about my work" button on every page (`assets/js/ask-azan.js` + `assets/css/ask-azan.css`)
talks to this Cloudflare Worker, which holds the Anthropic API key and answers with Claude
(`claude-opus-5-5`, low effort) using only the text published on the site.

Live endpoint: `https://azan-site-chat.azan-sapardi.workers.dev/chat`

## After changing the website

The bot's knowledge is a snapshot of the HTML pages (`src/knowledge.js`, generated by
`scripts/build-knowledge.mjs` — it includes `index`, `academics` (incl. the publication list),
`students`, `webapp`, `personal`, `blog` and every `blog-*.html`). Redeploy so it learns new content:

```bash
cd chat-worker
npm install        # first time only
npm run deploy     # rebuilds knowledge.js, then wrangler deploy
```

New pages outside that list need adding to `CORE` in `scripts/build-knowledge.mjs`.

## Local testing

```bash
# chat-worker/.dev.vars (gitignored):
#   ANTHROPIC_API_KEY=sk-ant-...
#   ALLOW_LOCALHOST="true"
npm run dev                                   # worker on http://localhost:8787
python3 -m http.server 8000 --directory ..    # site on http://localhost:8000
```

The widget automatically uses the local worker when the page is served from `localhost` / `127.0.0.1`.

## Key, limits and cost

- API key: `npx wrangler secret put ANTHROPIC_API_KEY` (stored encrypted in Cloudflare, never in the repo).
- Only `https://azan.biomechemical.com` may call the endpoint (`ALLOWED_ORIGINS` in `wrangler.toml`);
  each visitor IP gets 8 questions/minute; questions are capped at 1,500 characters, history at 12 messages,
  replies at 1,500 tokens.
- The ~25k-token site snapshot is prompt-cached: roughly $0.01–0.02 per answer while warm, ~$0.12 for the
  first question after 5 idle minutes. Set a monthly spend limit in the Anthropic Console as a backstop.
- `npx wrangler tail` shows live requests, including a `usage` line per answer.
